# התקנה על המחשב (Windows או Mac)

כ-15 דקות בפעם הראשונה, ורובן התקנה אוטומטית. אחר כך מפעילים בלחיצה כפולה.

## 1. מתקינים Python (פעם אחת)
- הורדה: https://www.python.org/downloads/. מומלצת גרסה **3.12** (גם 3.11 ו-3.13 עובדות).
- **Windows**: במסך הראשון של ההתקנה מסמנים ✅ **Add python.exe to PATH**, ואז Install Now.
- **Mac**: מתקינים את הקובץ שהורד. אחרי ההתקנה נפתחת תיקייה, ושם לוחצים פעמיים על **Install Certificates.command**.

## 2. מורידים את הקוד
1. נכנסים ל-https://github.com/guyos2/basketball (מחוברים לחשבון GitHub).
2. בכפתור ה-branch (משמאל למעלה, כתוב בו `main`) בוחרים את `claude/basketball-video-analysis-app-cv5xgk`. אחרי שהקוד ימוזג ל-`main`, אפשר להישאר על `main`.
3. **Code** (הכפתור הירוק) ← **Download ZIP**.
4. מחלצים את ה-ZIP לתיקייה קבועה, למשל `Documents\basketball`. לא מריצים מתוך ה-ZIP עצמו.

## 3. מפעילים
- **Windows**: לחיצה כפולה על **`start.bat`**.
  אם מופיע "Windows protected your PC": לוחצים **More info** ← **Run anyway**.
- **Mac**: קליק ימני על **`start.command`** ← **Open** ← **Open**. בפעם הראשונה צריך קליק ימני, כי זה קובץ שהורד מהאינטרנט. אם זה לא עובד: פותחים Terminal, גוררים אליו את הקובץ אחרי המילה `bash ` ולוחצים Enter.

**בפעם הראשונה** החלון מתקין את כל מה שצריך. ההורדה היא כ-1GB, ולוקחת 5–10 דקות. בסוף הדפדפן נפתח לבד על http://localhost:8000.
**מהפעם השנייה** הממשק עולה תוך כמה שניות.

- **החלון השחור** צריך להישאר פתוח כל זמן העבודה. סגירה שלו מכבה את הממשק.
- **הניתוח הראשון** מוריד את מודל הזיהוי (כמה MB), ולכן מתחיל קצת יותר לאט.
- **הסרטונים והתוצאות** נשמרים בתיקייה `workspace` שבתוך תיקיית הקוד, ונמחקים אוטומטית אחרי 48 שעות.

## עדכון לגרסה חדשה
מורידים ZIP חדש (שלב 2) ומעתיקים את הקבצים שלו על התיקייה הקיימת. מאשרים להחליף קבצים, ולא מוחקים את `.venv`. בהפעלה הבאה `start` מתקין רק מה שהשתנה.

הדרך הנוחה יותר לעדכונים היא [GitHub Desktop](https://desktop.github.com): עושים Clone למאגר פעם אחת, ובכל פעם לוחצים **Fetch origin** ← **Pull**.

## מהירות
- **סרטון של 30 שניות** על מחשב נייד רגיל: תנועת המצלמה כדקה, וזיהוי השחקנים עוד כמה דקות. בהגדרות המתקדמות אפשר לבחור "ניתוח כל פריים שני", וזה חוסך כמחצית מהזמן.
- **Mac עם שבב M1/M2/M3**: עובד, על המעבד.
- **מחשב Windows עם כרטיס NVIDIA**: אפשר להאיץ פי כמה. פותחים את התיקייה ב-Command Prompt ומריצים:
  ```
  .venv\Scripts\python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124 --force-reinstall
  ```

## אם משהו לא עובד
| מה רואים | מה עושים |
|---|---|
| `Python 3.12 was not found` | מתקינים Python לפי שלב 1. ב-Windows חשוב לסמן Add to PATH. אחר כך מפעילים מחדש את המחשב ומנסים שוב |
| `Installation failed` | בודקים חיבור לאינטרנט ומפעילים שוב. ההתקנה ממשיכה מאיפה שעצרה |
| הדפדפן לא נפתח | פותחים ידנית את http://localhost:8000 |
| `address already in use` | הממשק כבר פועל בחלון אחר. סוגרים אותו או משתמשים בו |
| כל דבר אחר | מעתיקים את ההודעות מהחלון השחור ושולחים לי |
